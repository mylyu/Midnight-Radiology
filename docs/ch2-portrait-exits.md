# 第二章第五夜 · 小雷立绘串场修复

## 问题与改动

- 用户截图为 `c2n5_chat_q`。前文确有小唐、小雷在茶水间，但公共选题页被硬编码成小雷立绘，每次其他话题结束又把他切回来。该公共菜单改为空立绘；人物真正回答和收到礼物时照常显示。
- `c2n5_sms_lei_pending` 是手机消息，强制空立绘，防止旧档里的 `viewSprite: char_lei` 被继续使用。兼容旧游标的 `c2n5_n7/n8/n8a/n8b/n8c` 微信段同样清空现场立绘；不误改成电话、不新增头像或配音。
- 原第二章先用上一步保存的 view 渲染，之后 effect 才更新；切换和旧档恢复可能短暂出现上个人物。抽出 `ch2SceneView`，渲染与保存使用同一套原有推断规则，让当前节点从第一帧就决定背景与人物，不等下一次 effect 清场。
- 当面的小雷对话 `c2n5_chat_both1/both3/plain`、走廊回礼 `c2n5_payoff_lei0/lei1`、奶茶/零食回复保留。小唐、老周及患者各自立绘不删。原数据只变 7 处 sprite 字段。
