## 对齐了什么

| 对照维度 | 第一、二章的实际基准 | 第三章本轮处理 |
|---|---|---|
| 普通对白 | 同一底部面板、点击场景补全文/推进、选项缓冲 | 保持共用组件及900/300ms保护，不增加推进按钮、不加逐字音 |
| 班后经营 | 有背景的两列数值卡、五颗圆点与准确数字、设备/背包/章节列表、底部功能 | 第三章使用相同结构，正文滚动、功能栏固定；第五班明确前往晨会；章末汇总显示本章净变化 |
| 书页 | 黄纸棕字、页码、上一/下一页、合书 | 替换深色折叠列表，每班四页；不改原有每班一次翻书收益 |
| 班末交接 | 主动点结算，不被普通翻页带走 | 增加“本班结束 · 结算”，背景快点不能结算，原工资不重复发 |
| 商店 | 无法使用/购买时要告诉玩家原因 | 咖啡待用、最后班停售、已持有、限购及余额状态与现有交易规则一致；不再能点却无响应 |
| 看图与观察 | 应能边看图边选 | 胆石观察题和两条短反馈保留刚才的同一切面；换角度后不冒充又一张采集图 |
| 人物与通讯 | 在场才显示立绘，通话对端不随说话人改变 | 老周/雯雯整通电话固定远程头像，主角接话仍显示原联系人，结束后退场 |
| 手机实验 | 图片和主操作清楚，解释不挤在微小图内 | M模式缩减空白，必要轴名放大；回波图缩短图内文字，保留原计算、控件与说明 |
| 对白与节奏 | 具体物件、有接话对象、一两句收住，不解释笑话 | 压短首班连续定义；第四班补上午临床跟班到午后练习的过渡；小何闲聊不再重复找纸巾 |

不照搬旧局限：第一章经营页在手机上需要滚动才能找功能、选项括号行动力和部分提前泄题的旧表现，不恢复到第三章。
