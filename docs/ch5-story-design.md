# 第五章《微光》本地实现与承接

2026-10-10；基于 `codex/chapters-3-5`。正文数据为 `app/src/game/ch5.ts`，共享章节运行时由主 agent 负责。本文件记录故事实现，不能代替浏览器试玩或素材看验。

## 作者最新方向与旧总线的差异

作者追问神秘病人的身份、父亲下落、老周离岗和隐藏黑手后，接受新收尾方案进入第三至五章开发。旧总线“神秘病人永不揭晓”的规划因此被本次方向替代；临床不确定仍保留。

- 神秘病人为退休长途客运司机许建平，父亲许守义。每年十一月来院，同时有现实症状与查询旧记录的动机。前章仅核到1998年转诊去向，不提前得知结局。
- 第五章经身份关系、两院转诊索引和外地留存记录交叉核验，确认许守义2001年在外地病逝；真正属于父亲的旧影像复制件在晨会之后交付。父子争吵后他独自就诊，转院后暂住老工友家，本来想把病看完再回禾川；2000年寄出的信因儿子迁址而退回，双方未能重新接上。医院记录与老工友家属回函、退信信封分开核验，不能只凭一个陌生人叙述确认。许建平承认自己当年嫌父亲反复念叨不舒服，吵完就出车，与第三章寻人启事段承接。
- 父亲不是流浪老人，也不是1998年无名胶片患者；与数据黑手无关。旧原件不会被主角拿到手机上。
- 许建平自己的PET仍需医师进一步评估。找到父亲没有顺便让病灶消失，也不把一个SUV或延迟变化当成确诊。
- 小雷是试运行前未经授权的技术合作发起人、院内样本整理/导出者，并已领取技术报酬；韩经理是接下后续商业用途与交付的厂家合作方。揭示依据接收方独立保管的首版提案、批次、原授权、合作登记及厂家结算/付款凭据，不靠账号或一句自白。小雷后来留证、断网仍真实有效，与原合作和隐瞒分别记录；权限暂停、报酬及岗位责任进入正式核查，礼物不改调查结果。
- 匿名短信发信人改为既有厂家销售雯雯，使用第一章已有`char_wen`与`wen`，无新增语音。原工作号不同于后来的名片号；厂家原联系人登记、两条短信发送记录及她交出的两版附件经核验后才揭身份。她见过同批样本的商业用途附件，回收单又不写如何留本地回执，担心原件随盒子被拿走；技术附件已有小雷，因而直接提醒现场值班者保留设备。第三章已完成回收单电话者才追加那次具体对话回声，不凭旧名片推断她早已承认发信。
- 老周2024年退休后返聘，2028年在进修出发前正式离岗，赴田头技术大学做校外带教。收好旧杯后，他看见证件不全的老人已有临时身份与申请号，主角、小唐和值班医师照常接上检查、解释及救助联系人，他没有伸手接申请，提杯离开。第一章旧`pat_oldman`复用，不把神秘病人立绘当流浪老人；仅有`zhou_truth`时主角认出2024年的旧人。之后大学来电与主角回县带新人相呼应，不升成医师或主任。

## 存档与前章回声

本章节点、旗标、徽章以`c5_`命名，收益与选择持久化由共享运行时去重。`adapt`只在现存前情成立时给回声：

- `c2_payoff_zhou_cup`：老周认出自己送过的杯子。
- `zhou_truth`：主角认出离岗门口的老人是2024年老周照顾过的那位；没有旗标只呈现眼前老人。
- `dlc.dr.served`确含`p_qian`：老钱认出主角；没有该记录则中性初见，不替玩家造DR经历。
- `data_audit`：正式核查呼应当年的会议表态，不让其他表态跳过后续核查。
- `c2_terminal_receipt_seen`、`c2_terminal_sms_seen`：旧回执和匿名短信的亲历回声。
- `c4_receipt_conflict`：前章删除回函矛盾与独立清单对照。
- `c3_wen_copy_kept`：雯雯在核验电话中提起第三章留核对联、不签回收联及她保存新版附件；缺此旗标不补造通话记忆。
- `c4_father_transfer`：父亲查询沿既有转诊线索继续。
- `c5_father_applied`：窗口按原编号继续核验，不重复开申请；跳过可选查询者在主线补齐受理，因此不会卡尾声。
- `archive_film`/`mystery_told`：领父亲复制件时可明确与旧无名胶片区分；没有旧经历则只核对父亲本人的姓名与登记号。

独立证据必经节点`c5_s3_records_4`记`c5_lei_origin_verified`，不发新的数值或勋章。主动核对选项的`c5_source_checked`和`c5_source`保留原用途；`c5_han_identified`保留为厂家合作方责任。旧节点ID、五班结束、工资、三份回礼、考核及凭证均保留。

本轮新增25个静态节点：`c5_pro_receiving_0..8`、`c5_s3_records_0..4`、`c5_s3_sms_reason_0..3`、`c5_epi_father_0..6`。原来电提示入口`c5_s3_reveal_5`、`c5_s3_sms_0`和`c5_epi_after_6`未移；`sms_reason`延续同次电话，不另加铃声。新增资源引用仅是已有`char_wen`、`pat_oldman`及`bg_corridor`；无新媒体或配音。

`c4_neck_followup`由前章记载左深颈部持续异常；本章临床描述固定对应这个问题。头痛/脑白质高信号不能替代其PET指征。
