# LDCT三个候选短篇 · 本地交接

基点 `d800020`，分支 `codex/ldct-three-short-stories`。本轮仅本地，未推送、未部署。三个故事供作者比较，**不表示三件事全部进入正史**；15–20分钟为设计目标，非计时验收结论。

## 内容与实现

- A《模体里有张脸》：完整模体中的点、弧与噪声引起联想；走廊声音在本篇解释，嘴硬与提前查看都有回响。不接1998、终端或匿名人。
- B《这顿饭谁请》：陆舟吹嘘盒里物件值钱，硬币/戒指/零件试猜、改猜或开盒影响请客/取餐对白；不扣科室金币。原物参照暂盖住，先看完整投影、轮廓、孔洞；结尾揭螺母，不靠换数据反转。
- C《这张片子是不是糊弄我》：家属误解低剂量，陆舟不耐烦引发冲突；劝和、先听、硬话三路均由医师及时接手。实验在下班间隙，不让患者等五轮教学；末尾简短互相道歉。
- 每篇一个休息枢纽，可选闲聊完成即隐藏，购物后当面送礼。价格、奶茶购买加人心、零食送出加人心沿用。没有署名、审批、盲评与汇报工作台。
- 同一 `LdctLab` 接收 `dataset/goal/concealTruth` 配置；一次有意义的操作就能继续，求助直接回对白，不要求试遍参数或双重确认。机架联动保留，更多参数/响应曲线展开查看。
- 对话继续直接使用 `DialogueScene`、共享打字速度和选项保护。点整个场景补全文/推进，900ms缓冲与300ms静默保护保持。没有修改主游戏互动、音源或配音。

## 存档与奖励

`dlc.ldct.ldctStories` 包含 `active`、`slots.face/dinner/patient`、`legacy`、共用 `receipts` 和 `experienced`。`dlc.ldct.ldct` 作为当前篇显示门面，与槽位在一次更新内保存。

- 首次读旧四段存档进入选择页；旧对象原样置于 `legacy`，不编造新经历、不覆盖其他章节。
- 换故事仅取消当前选择；续玩恢复该槽。重玩只重置选中的篇目，累计属性、物品、旧勋章和共用奖励收据保留。
- 首次操作/求助完成：医术＋1；五种体验都留过记录：家业＋1。三篇及重玩共享这两张收据；旧版已领收据照样认账，不再发一次。
- 礼物即时消费，人物回应与消费原子保存；一次同事在一篇内只接受一次。买咖啡本篇一次。选择/实验结果都有状态和来源校验，重复请求不能再领奖。
- 结束页的属性是跨章累计；“本次开始以来”含期间切换其他候选带来的全局变化，不是一套新伦理或科研分数。
