# 三章体验修订的纯状态验收

新增 [trilogy-experience-state.mjs](../app/tests/trilogy-experience-state.mjs)，只调用生产状态函数并读取实际章节数据。测试不构建、不启动浏览器、不播放音频、不访问玩家存档；模拟计时完成的状态路线不能称为浏览器试玩。

范围按新增扫描持久化、商品消费与数值提示的风险选择：

- 13处真实扫描：采集节点不提前展示结果/发奖励，普通推进不能绕过；首个时间戳经过JSON刷新保持，2999 ms不能完成，3000 ms把完成回执、结果游标和入节点回执一起保存，迟到回调/重复进入不重复奖励；不合理的远期时钟可以恢复，避免永久卡住。
- 六件新商品：钱不够不买、实际价格扣一次、购入背包并留下购买计数、持有不重买；沿实际选项与短场景完成消费/使用旗标/奖励，刷新后隐藏使用选项，消费后不上架、不重买。最后故事窗口仍可买，最后结算/考核/尾声关闭已过使用机会的商品。
- 第四章最终眼罩：最后一班hub购买，临床交班后在 `c4_5_after_shift` 使用，完成到 `c4_5_end`。该休息窗口在结算前；不声称能在最终经营页买完再回旧场景，也不把直接调用商店API当成界面已有入口。
- 数值提示：单独负行动力、打卡、新班重置、重玩初始化和收入安静；真实购买成本、赠礼人心、翻书学习、正行动力及伴随行动成本的学习仍显示真实差值。
- 旧节点与存档：只在内存中执行基点 `7fad7b7` 的三个小章节模块，检查旧游标ID/人物角色保留与当前图的后继有效；没有整仓冻结清单。每章一条生产纯状态路线覆盖五班、打卡、结算、扫描/教学、五题、真正尾声和凭证，并保留第一二章身份、已有凭证和其他DLC/另一章进度。
- 班次：验证实际开始节点的日间背景、第三章下午出发后夜间床旁阶段，以及第五章下午PET门诊的实际采集/结果背景；第五章序章按 `checkinAt` 到正式晚班才打卡。不是只检查源文件含“白班”等词。

从 `app/` 运行：

```powershell
node --import tsx tests/trilogy-experience-state.mjs
```

输出固定在仓库外 `../trilogy-experience-review-20261010/trilogy-experience-state.json`，只保留本轮案例摘要与失败证据，不写大存档快照或新增历史哈希冻结层。筛选结果另存，不能把仅一个案例的PASS冒称全文件重跑通过。

最新课件结构实际执行一次约1.46秒，全文件通过：13处扫描、六件商品、最终眼罩窗口、三章提示政策、三章旧游标/角色与后继图、三条完整生产状态路线均通过。当前路线为CH3 193次、CH4 196次、CH5 199次状态转移，各五班、五次结算、五题、真正尾声与凭证；不是浏览器通关。课件重排后的新工具与可选审计/档案支线没有使这些保护断言失效，因此没有删除或放宽任何行为断言，也没有更改背景、商品或奖励的精确预期来凑通过。

早期素材修订首次执行曾有一项测试预期错误：第五章 `c5_s4_0` 先在日间控制室接电话，`c5_s4_3` 才到日间候诊区，原断言误把两处当同一个房间，已按实际“电话→当面”过渡修正。这是测试错误而非产品bug，当前精确房间断言保留。早期筛选复跑报告仍为 `trilogy-experience-state-focused.json`；固定全文件报告已由上述最新课件执行更新，不再把它称为未覆盖的旧失败版本。

按主任务单独授权，旧 `trilogy-state.mjs` 仅补上扫描分支：调用生产 `beginTrilogyScan` 保存时间戳，再以开始时间+真实duration调用 `completeTrilogyScan`，保留提前一毫秒不可完成、完成后游标与收据一致、迟到回调不重复结算断言。新增扫描摘要，不改其旧工具默认值、奖励、选项、路线、凭证或其他保护预期。此收尾没有运行该旧文件的六条路线，也未扩大全回归；新专项已实际验证同一套生产扫描函数。

纯状态不能证明扫描图像、声音可听性、实际点击防误触或手机布局；这些由主任务的定点/浏览器验收承担。
