## 图像实现

- `EchoDopplerSpectrum.tsx` 在既有彩超图下方显示代码绘制的搏动频谱示意，不是王叔实测的流速。四个周期、固定纹理，不标临床数值；只在 `echoSpectrum` 节点出现。纹理合并为7条透明度路径并memo，避免对白打字时重复生成数千DOM节点。
- `UltrasoundImageGain.tsx` 从章节预加载的原图解码一次，画布宽不超过840像素。每次控制变化都重新读取原始像素，不累积变换、不移动肝肾结构。总增益作用全图，深部补偿从上方五分之一以下平滑增强，起始深部明显偏暗。
- 这是固定B图的显示增益示意，不是RF重建或额外曝光；原任务的数值、按钮和存档接口沿用。没有liver配置的旧任务仍使用原模体。
- 图像解码失败显示可继续的短提示，不影响“结束练习”；不会等待声音结束。所有修改共用现有900/300ms保护、原对话点击方式和3秒采集。
