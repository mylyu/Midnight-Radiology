## 素材与算法边界

生成模式为内置imagegen，完整角色/背景/医学图提示词见trilogy-*-generation.json及image-jobs.json；导入哈希/尺寸见trilogy-*-assets.json。原图在生成目录及外部档案，新交付图实际存入app/public/assets/media。旧候选可恢复归档，不在public堆原图或过期版本。

US模体固定几何/散射场，随探头位置重新采样，三类声束/深度/接收增益实际改变显示，声影沿射线遮挡计算；不是静态图加滤镜。MRI三对比及腕部两对比为非定量虚构同层图，不冒充实测序列；运动对照为重影演示，不声称软件校正。PET对齐用同源CT底/仅摄取层，衰减点阵为确定性相对活度，不冒充粒子仿真。可选手册容纳设备认识，玩家不看也能通关。

临床核对主源：SMFM Consult45的10–12mm轻度增宽、详细评估/随访与MRI补充；FDA超声成像/CDC无菌耦合剂相关用途；RadiologyInfo MRI安全/PET及神经/肌骨影像；SNMMI/EANM材料见各章专题。没有把临床护理检查单做为核心玩法。
