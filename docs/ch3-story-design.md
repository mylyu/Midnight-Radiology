## 八个工具接口

全部 `kind: ultrasound`，不设置variant。每次只有一个明确比较目的，使用同一目标的数据；共用界面和数值实现由主任务维护。

| 节点 | task | 目的与next |
| --- | --- | --- |
| `c3_s1_aunt_6` | `probe` | 探头/声窗与浅表目标；到 `c3_s1_aunt_7` |
| `c3_s1_gain_1` | `echo` | 移动同一目标，看回波时间与亮点深度；到 `c3_s1_gain_2` |
| `c3_s2_depth_1` | `depth` | 目标完整覆盖、画面比例；到 `c3_s2_depth_2` |
| `c3_s2_plan_6` | `tgc` | 总体增益与深部补偿；到 `c3_s2_finish_0` |
| `c3_s3_motion_2` | `m_mode` | 固定观察线沿时间回看，B当时位置与M轨迹对应；到 `c3_s3_motion_3` |
| `c3_s4_doppler_3` | `doppler` | 同一血流的探测角度与相对方向；到 `c3_s4_doppler_4` |
| `c3_s5_assess_1` | `resolution` | 扫描线/深度/横向采样与帧频；到 `c3_s5_assess_2` |
| `c3_s5_assess_3` | `gain` | 保留明暗层次；到 `c3_s5_assess_4` |

最后一项resolution对齐实际已实现的线数/深度模型，不假称控件改变脉冲长度或声束宽度。轴向短脉冲、横向窄声束的知识放在卡片/书页；线排密只改变采样。depth旧控件没有等待时长图，因此操作提示只要求看覆盖和比例，时间/帧频留给第五班的实际显示。M型实际控件是沿时间回看，观察线已固定，不要求玩家拖一条不存在的选线控件。
