# LDCT 开场实验台：数字模体与重建记录

本页记录本轮**实际实现**，不是后三段深度学习方案的实验结果。公开游戏中不含患者影像、模型权重或临床原始数据。数值源由仓库脚本离线生成；游戏仅加载一份小型无损图集。

## 数据、算法与可复现参数

- 原创圆柱数字模体：160×160，像素间距1.2mm，三个相邻轴向截面；包含明暗大嵌件、三根细杆和一个低对比小球。不同层是同一几何对象的相邻截面，不是三张独立噪声图。
- 平行束240个等间隔投影角，0至180度；三个信号档都保留全部角度，**不把少投影当低剂量**。
- 入射计数分别为900、9000、90000。每条理想射线按 `I0 * exp(-p)` 生成泊松计数，再取负对数。计数下限为1；未加入电子噪声、散射或厂商预处理。
- 根种子2258；相邻层种子分别为2258、2358、2458，三个信号档均复用对应层种子。同一层、同一信号的所有算法严格消费**同一份带噪投影**。
- FBP：`skimage.transform.iradon`，ramp滤波。
- 迭代示例：5轮SART投影一致性更新（松弛系数0.15），每轮之后做TV约束步骤和非负截断；TV权重依次0.00012、0.00050、0.0020。是实际重复访问投影的 **SART–TV教学实现**，不是对FBP图加滤镜，也不冒充厂商临床重建或深度网络。
- 显示窗全程固定为线性衰减系数0.008–0.024/mm。数值源为float32归档；显示图线性映射为8bit，再无损WebP编码。无损是针对显示像素，并不声称8bit保留全部浮点动态范围。
- 深度学习按钮仅显示“还在训练”，本轮没有神经网络推理、神经网络比较结论或伪造训练进度。

生成环境：Python3.14，NumPy2.5.0，SciPy1.18.0，scikit-image0.26.0，Pillow12.2.0。脚本与参数是可再生成依据，未来更换数值库需重新验图、验证结构和更新素材版本，不能只换图不换参数记录。

从仓库根目录执行，输出选择仓库外独立目录：

```powershell
python scripts/generate-ldct-phantom.py "../ldct-opening-assets/phantom"
python scripts/check-ldct-phantom.py "../ldct-opening-assets/phantom"
```

生成物包括原始模体、理想/带噪投影、计数、所有重建结果的压缩NPZ，逐结果参数/哈希JSON，审阅拼图 `review.png` 和交付图集。**NPZ、审阅拼图、计数等不放正式public，不增加玩家下载量**。Kimi可使用脚本与本文再生成；本机完整数值记录保留在 `../ldct-opening-assets/phantom/`。

## 图集与观察效果

- 逻辑ID：`ldct_phantom_v1_atlas`；版本 `ldct-phantom-v1`。
- 2080×480，13列×3行，每格160×160。前12列为3个信号档×（FBP、三档迭代），第13列是原模体。三行对应相邻层。
- 交付文件328,424字节（约321KiB）；SHA256 `099971caf68d70109c1d0991941e4cff50d9670187ff37dc66b5ec6c4b615b45`。
- 图集经Pillow无损解码逐像素核对；导入请用 `--keep-webp` 保留已验证无损流，不使用默认有损导入。
- 两轮任务不预先圈出位置；第一轮保存比较后可以看大嵌件，第二轮保存后可看弱小结构的已知位置。圈不准、求助和不确定都可正常完成；并不以找到某一个圆作为技能奖励门槛。
- 参数保存在受控 `LdctLabState`；固定A与当前B必须为实际不同的配置（FBP的无效“强度”差异不计）。保存对照后先显示已知结构入口，再由玩家收进记录；刷新不会重新揭答案前的初始状态，也不会自动增加奖励。
- 原模体所在图集并非安全考试答案：教学站点前端当然可检查资源。重点是正常交互中**比较之前不泄露答案**，不是保护考试秘密。

中间层的实测示例（衰减系数/mm，统一ROI）：

| 方法 | 弱嵌件局部对比 | 均匀区域标准差 |
| --- | ---: | ---: |
| 中信号FBP | 0.001533 | 0.001262 |
| 中信号轻迭代 | 0.001649 | 0.001762 |
| 中信号中迭代 | 0.001533 | 0.000713 |
| 中信号强迭代 | 0.001076 | 0.000108 |

已看12种中间层对照：信号差异、强约束的平滑及最细杆/弱圆变淡可见。强迭代的噪声降低伴随约30%的弱对比损失；轻迭代在中低信号下甚至可能比FBP更吵。因此**不设置算法排行榜、不把“迭代”“更平滑”直接判优**。量化数字是开发验收，不作为玩家公式题，也不能推及真实临床算法的所有任务。

## 方法局限与来源

这是二维平行束、单能、固定几何的简化实验，未建模真实CT能谱、散射、运动、探测器响应、束硬化、三维锥束和临床病变。信号档不是mSv、CTDI或患者处方；不外推临床剂量、不声称取得诊断效能。原始数字模体为项目原创，遵循仓库原创素材许可证。

- [AAPM Low Dose CT Grand Challenge](https://www.aapm.org/grandchallenge/lowdosect/)：参考其“共同数据、投影噪声与任务可见性”的比较思路。**没有使用该挑战患者数据**，也没有声称完整复刻其仿真；该挑战本身对图像域去噪与投影域重建作出区分。
- [scikit-image Radon transform官方示例](https://scikit-image.org/docs/stable/auto_examples/transform/plot_radon_transform.html)：FBP和SART接口及实现依据。
- [scikit-image TV restoration官方接口](https://scikit-image.org/docs/stable/api/skimage.restoration.html#skimage.restoration.denoise_tv_chambolle)：本例每轮迭代中的TV步骤。算法库依各自许可使用，不改写为项目原创算法。
