## 历史测试的处理原则

过去若干轮测试把整份第二章源码冻结为旧剧情，本轮经批准新增节点、换图和换音后，不能直接把旧快照当作当前剧情要求。`ch2-pacing-source-deltas.json` 明确列出本轮原文/新文差异，历史测试只逐项逆投影这些已批准差异，再运行原断言；不是直接加载旧 Git 文件冒充现版本。

当前版本另有实际运行的剧情、发放、连续通关、媒体与第一章冻结测试。旧轮断言与新轮 live 验证分开记录；不删除奖励、路由、素材、第一章保护断言来强行通过。
