# LDCT：从追影子开始（本地重做）

基点 `3cc80e2`，分支 `codex/ldct-projection-rework`。旧版实验只比较最终图，缺少投影因果，且另做对白界面；本轮按作者反馈替换，不以旧方案约束新玩法。仍只实现第一段，后三段科研/临床伦理/深度学习的完整冲突没有提前制作。未发布。

## 玩家实际做什么

| 时间/衔接 | 操作 | 能看见的因果 |
| --- | --- | --- |
| 约饭后，值班室 | 点一个小结构、拖动角度，再换个结构 | 点没动，从不同角度测到的位置变了；右边正弦轨迹与左边结构同色对应 |
| 小雷取充电器，临走多看一眼 | 把更多方向的投影铺回去 | 条纹交会出结构；方向足够多也仍有模糊，不把少角度当低剂量 |
| 次日午饭后 | 拖动分界比较Ramp、Shepp–Logan、Hann | 同一份投影，滤波器在反投影前处理；看细杆和噪声的取舍 |
| 两天后，陆舟取转接头 | 降低光子数，联动看正弦图和FBP | 噪声先出现在测量里，锐/柔滤波改变结果；固定角度与种子 |
| 倒杯水后继续 | 一次走到1/2/4/8轮，可倒回、停住，比较预测和实测投影/差异 | 真正逐轮SART，不是假渐变；更贴合测量不保证更清楚，可能追噪声 |

每个画面只出现相关工具；保存或求助后回到人物对话，不强迫答对、不输入公式。没有新增普通对话音效、病例/临床资料或额外扫描。原奶茶、零食、咖啡规则及一次医术/家业奖励保留。
