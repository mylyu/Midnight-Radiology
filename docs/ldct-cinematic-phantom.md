# LDCT近景、实体模体与手动实验打磨

2026-09-28，基点 `b91b46f`，分支 `codex/ldct-cinematic-phantom`。本轮仅本地，未推送、部署或导出Kimi包。承接已实现的父亲故事，不重做第一二章、DR/DSA或普通对白操作。

## 作者本轮要求与实现边界

- 增加一起吃饭、研究未开通的迭代包、搬实体模体试扫、陪父亲检查四种近景。
- 当前故事中的模体改为真实搬运、安放、扫描和归位的圆柱形实体模体，不再把开场写成只在电脑里造一个圆。
- 曝光和迭代增加手动体验次数：曝光1→13份，迭代0→12轮；正常继续至少经过十次逐步推进，仍保留求助带过。不自动播放，不通过插值或图像磨皮假装计算过程。
- LDCT角色出场语音暂时下架，保留电话铃声。主游戏及其他DLC的声音不动。

## 实体模体与教学数据不能混称

当前第5版剧情增加三个节点，插在已有节点之间：

```text
lf_plan_2 → lf_phantom_0 → lf_phantom_1 → lf_phantom_2 → lf_review_intro_0
```

老周安排质控后的空档，两人搬模体、退出机房、按安排试扫，完成后归位，再到工作站查看投影/重建。对白以“塑料桶怎么这么沉”“里头的小零件比宿舍家当还齐”等具体动作衔接。次日医师结合模体对照和患者情况确认方案；不把模体参数直接当成陆叔的个体化处方。

**剧情实体模体不等于开发者真的采集了实体CT。** 游戏的圆模体过程图仍由对应结构的二维平行束数值模型生成；胸部仍来自开放实扫CT衍生的模拟投影。手册保留一次清楚的方法说明，不在每句对白中弹警告，不声称获得了源扫描器原始投影或实际开展了临床研究。

## 十二次逐步操作与兼容

数值生成、许可、参数、旧帧一致性和图集哈希详见[数值记录](ldct-deep-experiments.md)。新增无损图集共 **285,672 B**，复用已有帧，不重包整个序列。

- 曝光首档与刚看到的同层FBP一致，1→13份完整体验可点12次；每次累计同源独立泊松计数，按总入射量归一化后重新FBP，固定几何和显示窗。没有把亮度渐变、重复帧或少角度叫作加曝光。
- 迭代0→12轮，每次执行一整轮SART–TV对应的离线真实结果。三个相邻层保持对应；0/1/2/4/8轮复用原结果，新轮次不假借最近旧轮次的投影/残差。
- 正常继续要求至少10次推进，是本轮作者明确的体验要求；不要求一定选最平滑图，不把更多轮次判作临床更好。求助入口可带过，奖励与故事不因判断不准受罚。
- 新版实验使用独立版本与进度字段，旧记录的步骤不能突然解释为新轮次。第4版剧情JSON不改；当前第5版兼容原有节点，新增模体段不会把已经走过它的玩家强制倒退或重复检查。
- 普通下一句、消费、奖励、共享学习收据不改规则；本轮只是为当前工具增加更多实际可见中间状态。
