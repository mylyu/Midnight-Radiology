# 第二章：日常短句配音

2026-09-20 · 分支 `codex/ch2-natural-voices` · 基点 `1d7342d`。仅本地，不推送、不部署。

## 用户要求与取舍

用户指出「你拍我看着」「日检预热别偷懒」等配音尴尬、脸谱化，要求像日常说话，一般不超过8个字。此轮替换14个既有出场语音位（12个角色），全部4—7个汉字；不是把整章对白截成8字。同步改14个节点的开场文字，使说出的短句与页面开头一致，后文仍保留病例事实、角色动机与支线线索。

不再用「快就是医德」「新机器新规矩」「别偷懒」等口号或训话表达职业。不将父母写成出场即威胁医护的模板：先求助，再表达是否重复检查的担忧。小何仍用短促的「麻烦让一下」表现急迫，不加入警报或额外呻吟。

- 游戏源码仅 `ch2.ts` 的14个 `text/sfx` 及 `store.ts` 一行新语音前缀的音量配置变更。

- 新前缀仍是已有 `vox_ch2_*` 类型和语音识别范围；沿用旧播放/失败重试/章节内去重逻辑。新轨播放音量为0.45，与原人声相同；其他音轨音量不变。
- 不改App界面、交互、节点数量/顺序、选项文字、跳转、行动力、奖励、图片、存档结构或总线。第一章、DR/DSA源码不动。不会清存档或重置「互动完成即隐藏」。
- 完整前后文字及旧/新音轨映射：`ch2-natural-voices-changes.json`；短句/参考策略：`ch2-natural-voices-lines.json`。

## 生成与复现

本机 `auk-infer`、AuK-Flash、Qwen2.5-Omni-3B、bf16、cuda:0、cpu_offload，使用官方零样本模板 `Say the following with the same voice: "..."`。生成时长1.5—2.1秒；仅起始轻量静音裁切、约−20 LUFS/−2 dBTP响度处理，无变调、无变速。成品为24kHz单声道128kbps MP3，约1.38—1.98秒。

老周/小雷/小何/主任/大爷复用9月16日同角色固定声音参考；小唐/老范/小凯/雯雯/父母/值班医师取现有同角色录音作固定参考。老范两个分支、主任两条共用同一参考，SHA-256已校验。没有重新随机设计这些角色的身份音色，但短句情绪/自然程度仍需作者试听裁定。

- 原始候选、参考副本、无损WAV、参数、日志：仓库外 `../AuK/outputs/ch2-natural-voices-20260920/`。
- 可重跑脚本：`scripts/ch2-natural-voices.py`；最终全部为attempt 2，逐条种子、完整命令、参考/产物哈希在 `ch2-natural-voices-generation.json`。
- 最初attempt 1把附加表演说明混进语音，已全部弃用。原始失败候选仅留AuK输出目录，不作为游戏素材；脚本已改为官方精确模板，并禁止导出指令不一致的旧候选。不要把自然语气的长段备注追加到零样本台词模板后面。
- 没有调用云端付费服务，也没有上传患者资料。

## 验证与限度

- Whisper逐条转写和声学/解码检查：14条正文匹配，未识别出额外指令、重复句或漏词；注意「哎/诶」「还没/還沒」「他/她」是识别书写差异，不是音频内容不同。音频/检查哈希对应，非静音，无采样削波。见 `ch2-natural-voices-qa.json`。
- 隔离Edge实际加载、播放并自然结束14条新音轨，核对节点、短句、单次播放和0.45音量；不是只mock播放成功。试听页28个新旧播放器、连听/停止、手机无横向溢出、不读写存档检查通过。记录在仓库旁 `ch2-natural-voices-review/`。
- `ch2-natural-voices.mjs` 对基点严格比较：除明确列出的14个正文/音轨和新前缀音量以外，其余剧情、选项、运行时字段、UI及存档代码保持相同；旧音轨不被修改。
- 上轮叙事测试增加显式逆向投影：先核对本轮14处改文与清单一致，再还原到上轮输入，继续保护原58处叙事及64组条件状态。没有删掉上轮检查来掩盖授权范围变化。
- 本地Qwen音频感知仅作辅助，能转写多数短句，但多次回答音色/情绪无法判断，值班医师一条甚至未成功感知；记录照实保留在 `ch2-natural-voices-listening-model.json`。**不把它当作人工回听或自然度认证**。最终听感与人物辨识度请作者试听。
- 构建/TypeScript、剧情数据、收集发放、连续性、上轮叙事投影、本轮声音静态和实际浏览器播放测试通过。常规flow通过（含播放被拒后的点击重试、旧heard标记、桌面/手机开柜、关书/刷新、原▼操作和患者出场）；lint仍为原基线10 errors/2 warnings，构建有原有大包警告。本轮没有重走所有剧情结局，也未声称真实用户Edge随机卡死已根治。
