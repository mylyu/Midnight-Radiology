## 素材规则和清理

- 193张原尺寸有损WebP：Sharp 0.35.3 / WebP 1.6.0、q78、alphaQuality100、effort6，保持ICC。全部保持尺寸、透明通道逐像素一致；不存在为了保留透明处隐藏RGB而退回巨大的PNG。
- `ch2_needle_record_v1`小字证物使用无损WebP：26,928 B，与有损只差488 B，值得保留文字质量。
- `ct_head_hema`、`ct_lung`、`ct_wrist_simulated`是动态调窗数值源，原PNG文件与原始SHA256不变。单纯用于展示的其他CT图允许有损；观察区域坐标与素材原尺寸不变。
- 96条正式音频字节不变，合计3,387,868 B；12份连续断层图集字节不变，合计653,720 B。儿童仍不使用成人连续图替代。

- 移出194份已被替换的原PNG、295份旧生成缓存、6个公开试听HTML及2个候选试听MP3。运行时不再引用其实体URL；明确移除的8个试听文件附独立哈希。素材替换映射、原图Git blob、新文件SHA256/大小/尺寸/误差均见 `game-delivery-assets.json`。

## 加载方式

`image-assets.catalog.json`是受版本控制的稳定逻辑ID→带内容哈希文件名映射。构建只校验实体与预算，不需要原大图/Git历史/网络下载素材。旧`image-assets.generated.json`仅作为本地旧预览的兼容产物，生产不依赖它。

背景按需高优先级加载、解码成功后再切换，换场时保留上一张；19个`bg_*`场景首次进入有同背景48px内嵌预览，无额外请求。预览总计3,610 B图片数据，不是巨大的base64整图。`ch2_bg_breakroom_day`已压缩但未配内嵌预览，旧档直接冷恢复时仍先显示渐变；日出沿用原picture演出。自动最多三次尝试，始终同一个轻量URL，失败后保留手动重试且不锁剧情；不再回退大PNG。新增素材按 `media-import.md` 导入，构建拒绝遗留原大图、过期压缩副本、单张非数值图超过600 KiB或总图超过30 MiB，避免再次越积越大。

没有新增Service Worker或清空玩家存档。URL内容哈希帮助更新缓存；发布时已打开的旧版本标签页若仍请求被删除的旧URL，需要刷新一次。正常入口仍为不带版本参数的网址。

## 核验方法

- `game-delivery-freeze.mjs`：独立钉住媒体审核清单、4份精确源码变化；实际解码原Git参考与当前WebP检查尺寸/alpha，不把历史PNG冒充当前文件。其余剧情/存档/声音/图集及旧保护账本保持冻结。
- `game-loading-browser.mjs`：真实生产子路径、桌面/390px、冷缓存1 Mbps/120ms；当前本机模拟结果UI约2.8秒、清晰背景约4.2秒。另测被延迟响应时同图预览、三次失败后手动重试、197图实际HTTP/SHA256/浏览器解码。此为本地限速模拟，不是对每位用户网络的保证。
- 所有历史48项静态测试继续保留，明确媒体迁移身份后执行；不放宽剧情或奖励断言。历史浏览器夹具中已失效的开发试听路径不能冒称通过，正式连续流程另验。
- 类型与生产构建通过；全仓lint仍有既有10 errors/2 warnings，不在媒体交付中顺手重写无关UI。
- 全连续与补充浏览器结果、提交编号/发布状态见本轮 `HANDOFF.md` 顶部和回归文档。

## 回退与协作

按本轮三类提交（实体素材/加载逻辑/回归交接）逆序 `git revert`，不要hard reset或强推。回退旧构建时清理本轮生成目录须另核对路径；原图可从`c4215b0`恢复。不要把原图和新副本同时重新塞回public。

Kimi读取 `KIMI_IMPORT.md`、`HANDOFF.md`、全书剧情总线和本文件。无`.git`导入包可以直接`cd app; npm ci; npm run build`；历史冻结测试需要完整Git历史，缺历史不是要求删除测试。ImageCAS冠脉衍生序列采用非商业许可，**商用前须替换或另获授权**；保留`NOTICE`、`ct-sequences-sources.txt`及原许可记录。
