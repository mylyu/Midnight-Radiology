# 第二章局部对白与推进补丁

基点：`5fea950`；分支：`codex/ch2-minimal-fixes`。仅本地，未推送或部署。

## 用户最新裁定

- 肾结石患者先出场并语音抱怨，再进入医师讨论。
- 腕部病例不要反复出现AI来源提示，学生已知游戏由AI制作。
- 卡住不是特定节点，是偶发、刷新恢复。不能把钥匙节点通了当成全部解决。
- 约三成对白存在说教腔，应精简、生活化，保持趣味与角色冲突。
- 最后儿童复查配图不像儿童且似有血肿，要求重新生成。

## 已实现

### 病例顺序与语音

新增 `c2n1_pain`，路径为 `p0（患者图）→ pain（哎呦，疼死我了。）→ p1（小何）→ p2（讨论）`。原有 `vox_guy.mp3` 移到该节点，结束处不再播放；没有生成或改动录音。石头/腹痛患者虽然复用同一短句文件，现在分别记听过标志，互不吞掉首次出场语音。普通角色既有配音去重保持不变。

结石段同时去掉左右侧自相矛盾、承诺自行排石和拖到明早复诊的说法；由医师确认方案、急诊接续处理。

### 对白轻修，不重构剧情

改动84/320个已有文本节点，约26%；另精简9个选项标签。不机械凑满30%。保留全部旧节点ID、原选择去向、条件、风险概率、奖励、卡片、事件和调窗目标。仅患者首次出场多接一条短句。

重点：删长段参数背诵和格言式结尾；老周少总结、直接做事；陆舟像老同学，算法原理引到可选旧书；家长保留急躁冲突；小唐的牛肉纸条改成生活细节。主任两条开场同步此前已批准录音的“年轻人，白班要快”“年轻人不错啊，我出几道题考考你”。保留1998年、每年11月、封条柜、数据外传和后续审计等关键线索，不揭谜底。

逐条原文和新文在 [ch2-dialogue-polish-changes.json](ch2-dialogue-polish-changes.json)，供Kimi逐条审阅/回退。不是把整章重新写过。未改第一章、DR/DSA或总线文档。原版与总线在排班、退休时点、开柜内容等既有差异仍见旧交接记录；本轮不宣称已全部符合总线。

### 腕部提示与儿童图

删除腕部场景括注、腕部专用大图AI图注、调窗面板AI提示；任务正文只说调窗。保留原PNG、灰度映射和目标参数，不将它改称真实HU数据。生成来源继续保存在文档中，不反复打断游戏。

内置 image_gen 新增 `app/public/assets/ct_head_child_followup.png`，仅接入 `c2n5_m17`。旧图留给前面的旧片/头皮伤剧情，不覆盖其他章节。新图按6岁儿童、居中对称、无明显出血/占位/头皮隆起生成并检查；单张生成图不能验证年龄、诊断或临床解剖，不能作为真实患者资料。最终提示词、文件哈希见同一JSON清单。本轮不新增剧情内AI提示。

### 偶发“卡住”：证据与边界

1. 原版钥匙路径：在独立桌面/手机测试中均能走完，未复现该处死锁。
2. 已复现一种选项点击饥饿：原代码每次点击都会刷新计时，包括被拒绝点击。对话区点一下后，以100ms间隔连点选项5次，始终停在 `c2n1_p2`。
3. 改为节点级一次性接受选项；保留文字完成后的900ms防误触等待，但拒绝点击不再延长锁定。同一测试现在到达 `c2n1_p2a`，只结算一次。
4. 修复另一处输入无响应：原 `advance` 在选项/小游戏/结算节点先检查blocked，导致不能点一下显示全文。现在仅阻止导航，不阻止补齐文字。
5. 普通对话新增可聚焦“显示全文 / 继续”按钮，图片显示与鼠标点击不再是唯一推进提示。
6. 这些是实证修复与交互补强，不是已证明覆盖用户全部偶发卡死。若再次发生，需记录具体节点、是否仍有动画/音频、能否打开旧书，以及浏览器控制台异常。未清空用户存档，也未擅自操作用户浏览器。开发期间HMR和旧运行态尚需与真实运行故障区分。

## 科学表述边界

本轮缩短旁白时，把“重新重建薄层”与“重新扫描”分清；儿童复查交由医护评估，不拿个人剂量计当患者剂量；不再由BME主角根据六格检查单自行作停药/增强决定；运动伪影不再让人把手留在曝光范围内；故障先报修并按停机预案安排，工具箱支线保留但不擅自拆机。

参考核对：[ACR疑似结石](https://acsearch.acr.org/docs/69362/narrative/)、[ACR/RSNA儿童CT](https://www.radiologyinfo.org/en/info/pedia-ct)、[IAEA CT物理](https://pub.iaea.org/MTCD/Publications/PDF/Pub1557_web.pdf)。只是本轮涉及点的核对，并非全章临床审校。既有冠脉CTA病例危险分层/正确选项、部分旧卡和旧书中的绝对化医学说法仍待单独审核，不应据此宣称教材医学内容全部正确。
