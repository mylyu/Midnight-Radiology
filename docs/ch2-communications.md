# 第二章通信提示 · 2026-09-25

基点 `2ad0876`，分支 `codex/ch2-phone-cues`。本轮作者要求完成后推送GitHub与Pages。

## 呈现与范围

- `ch2-communications.ts` 显式登记29个节点，10个实际收到事件触发提示音；不做关键词自动匹配。旧聊天记录、正在发送、没有回音、转述旧电话不响。小雷连发三条只响一次，不逐句响。
- 小何手机响、陆舟约饭来电用新手机铃声；小何/小雷消息、两次匿名短信用新消息声；厂家失联来电、第五夜急诊电话等院内座机用现有 `ring.mp3`。现有带人物头像的院内通话不叠第二个浮窗或音轨。
- 32像素代码原生SVG电话/消息图标，不下载新图片；绿色情况为通话、蓝色为消息。显示发送者/来电者、设备和当前状态，不显示未来身份，不预泄露短信正文。陌生号码不擅自命名为厂家或陆舟。手机端位于顶栏下方，桌面右上角，不遮挡选项。
- 仅进入收到节点触发一次，标记 `c2_communication_heard_<node>` 先保存；刷新/返回/解除静音不重响，下一次重玩按现有c2旗标清理重新可播。单独通信静音设置保存在 `midnight-radiology-ch2-communications-muted-v1`，不静音已有角色配音。
- 离开、切后台立即停止；拒播/异常不重试晚到的铃声、不锁剧情。打卡、扫描、观察、送礼等临时呈现挡住正文时不提前挂载提示。组件key为`communication-<node>`，必须与盒子音效等同级组件不同，避免React错误复用造成重复播放。
- 无改对白/选项/奖励/人物立绘/病例，第一章、DR、DSA及所有既有素材保持原样。
