# 第二章通关凭证（2026-09-25）

基点`e34bba4`，分支`codex/ch2-completion-certificate`。作者要求模仿第一章：第二章通关后填写姓名、学号，盖章领取可截图提交的凭证。本轮仅本地实施，不推送、不部署。

## 实现范围

- `Ch2Settlement`仅在全章结束时显示姓名/学号表单及凭证，放在原延伸阅读上方；五次普通班后经营、晨会答题中和尾声尚未结束时不发证。原手册、徽章、书页、延伸阅读和大厅入口保留，不新增过场或锁住离开操作。
- 新`Ch2Certificate`参照第一章纸色、边框、原印章、盖章音效与“截图交作业”的形式。第一章已有姓名/学号时预填，但仍需明确确认领取；无身份或只有空白字符不能发证。手机长姓名/学号换行，印章使用独立布局位置，不盖住身份文字。
- 新`ch2-certificate.ts`只写`dlc.ch2.certificate`。快照包含姓名、学号、金币、本章现役勋章数（去重）、五班（三夜两白）、第二章晨会等级、种子和独立通关码。之后消费、收集、刷新都不改变已签发快照；重复点击/调用不重发、不重复盖章，不奖励金币或属性。原重玩函数清空第二章进度时自然清掉本章凭证，第一章身份、凭证算法、成绩、旗标、DR/DSA进度不动。
- 已通关旧档可以补领；有第二章测验记录时以该记录为准，未完成测验不能凭旧done标记领证。没有测验记录的旧通关档只使用有效`quiz2_grade`，否则写“未记录”，不借第一章成绩、不补造答题历史。
- 原教师验证页只新增“校验第二章凭证”入口，第一章原表单和`YSK`算法保持原样。新第二章页验证独立`YSK2`码，姓名、学号、金币、勋章数、班数、评级均纳入校验；严格拒绝空数值、数字后缀、小数、越界值和跨章凭证。可返回原入口验证第一章。
- 使用第一章同类轻量散列思路，但第二章采用独立盐、JSON字段数组和8位校验段。明确这是本地信息一致性检查，不是联网实名、防作弊或密码学签名。姓名学号仅随原游戏存档保存在本浏览器，没有新增上传服务。
- 无新图、声音、依赖或全局样式文件；复用现有stamp资源。未改第一章剧情、交互、发证函数，也未改第二章病例、奖励、扫描、考试或结算数值。
