## 存档与恢复约定

仍使用原总存档键；不清存档、不改第一章成绩、购买计数、关系旗标及 DR/DSA 进度。新增内容均在 `dlc.ch2`：

- `loop`：本轮标识、每班起点/结算快照、流水与送礼对象记录。
- `scanSessions`：每个入口开始时间及完成状态。后台节流后按墙钟恢复，已完成不重播。
- `observations`：已选回答及是否读完反馈。先原子保存选择/奖励，再显示反馈；刷新不会重新领分。
- `observationRewardShifts`：已获得本班观察奖励的班次。
- `giftReply`：送出后的回应；刷新继续该回应，不再次消费。

旧档从恢复点开始记录，显示“此前明细未记录”；不推测旧收入或倒退已完成章节。班后购买计入刚结束的班次，只有进入下一班才建立新快照。重玩清除第二章本轮字段，沿用原跨章属性/物品继承。

采集及观察期间，原结果节点的卡片、效果与解释延后到反馈结束；采集入口经审计无原奖励，因此自动接至原下一节点不丢奖励。图片载入失败仍可选求助并继续。所有新奖励与记录使用事件标识防重复。

## 验证与历史测试

第一章详细结果见 [ch2-loop-ch1-regression.md](ch2-loop-ch1-regression.md)：固定 `05889fa` 检查 30 个共享/第一章/DR/DSA 函数和 263 个原有媒体哈希；原五夜、CR 演出、商店、考核和刷新测试原样执行。

新增单元验证：`ch2-loop-ledger-gifts`、`ch2-loop-playback`、`ch2-loop-observations`、`ch2-scan-registry`。浏览器验证：`ch2-loop-browser`、`ch2-scan-browser`、`ch2-pacing-runtime-browser`、`ch2-collection`。历史数据/视觉/剧情投影继续验证，不用删除断言绕过新增阶段。

最终严格走查通过 **331 轮推进、278 个剧情节点、全部 17 个演出入口、12 个观察配置和手腕调窗、12 份病例交接记录、五班经营、晨会五题及尾声**。94 笔流水的金币、医术、人心、家业、行动力合计与真实状态变化逐项相等，没有重复事件标识。实际检查扫描/观察中刷新、送礼后刷新、无物品/急诊不送礼、原第三夜关东煮、缺图求助及错误回答继续。

桌面 1280×900 与手机 390×844 的经营界面在折叠/展开/滚动到底部均检验；底部入口保持可用，不以覆盖层挡住记录。旧媒体 20 个桌面/手机场景继续检查，小凯批准 B 音轨实际入口仍触发，儿童新旧片时间标签保留。`ch2-pacing-media` 仅把观察入口的预期文字由立即解释改为新观察问题，原图哈希、标签、语音与布局断言不删。

历史测试迁移仅对应获批变化：班后分享改为班后不可分享并检验当面赠礼；新经营按钮/收藏文本使用新标签；扫描路径以“一次采集＋一次重建＋无旧 xray 声”替代旧单音效断言；旧流程先完成新增观察/演出再推进。原奖励、节点图、计数、恢复和第一章断言保留。

`ch2-loop-source-deltas.json` 记录到 `05889fa` 的逐行反向投影，仅供历史测试使用，运行时不导入。投影对未列明改动、块内篡改和尾部附加均拒绝，且另有真实运行时/素材/回归测试，不能把旧文件直接当新文件测试。

已有全仓 lint 基线仍为 **10 errors / 2 warnings**，没有新增；主要来自未改的共享 toast、模板 UI 导出、sidebar 随机值及 store 常量。生产构建仍有原有大包体提示，不降低阈值遮掩。旧 `ch1-freeze-pacing` 固定更早的 `1452d78`，会因此前已批准三条配音映射失败；原文件保留，本轮保护基点使用 `05889fa`，不是把该历史失败写成通过。另一个原 `ch1-voice-revision` 是“从 `2d629e8` 以来只能有四个声音补丁文件变化”的一次性交付测试，本轮新增第二章功能后自然不满足该范围，未改宽其断言；批准声音的哈希和完整 store 由 `ch1-freeze-loop` 与 `ch1-approved-voices-projection` 独立严格复核。

浏览器测试使用独立 Edge 配置和隔离存档，不操作作者真实浏览器存档。截图和走查 JSON 放仓库旁的 `ch2-loop-browser-review/`、`ch2-loop-scan-review/`、`ch1-loop-parity-review/`，不装入游戏。
