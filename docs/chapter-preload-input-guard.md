# 分章节完整加载与选择防误触

基点：`fa01385`。分支：`codex/chapter-preload-input-guard`。作者明确授权验证通过后推送 GitHub / Pages。

## 实际改动

- 两章恢复原先“每次点击都记入”的 300ms 停手间隔。900ms 选项出现缓冲仍保留；持续快点不会选择刚出现的答案，暂停后再点即可。指针按下时未就绪、跨对话抬起、键盘按住重复触发均拒绝。第二章同节点的观察/求助/送礼有独立呈现身份。
- 普通翻页 300ms、购物 500ms、30% 风险概率、原子保存和所有剧情/奖励/素材/配音保持原样。不能直接撤销旧 `048f5e0`，否则会把正常的数值与存档修复也撤回。
- 进入章节前取得整章资源；不是在已经运行的剧情上盖一个加载层。进入、重玩、打卡奖励仅在准备完成且明确进入后执行。加载失败/取消不清档、不发钱、不消费声音或礼物。
- 章节资源来自导出的剧情及登记的动态渲染资源，不用文件名前缀猜章节，不扫描 public 全量打包。共用资源只取得一次；旧档已收藏卡片、证物和场景快照按实际需要补充。生成清单含实际文件大小和 SHA-256。
- 所有图片、原调窗 PNG、声音、切片图集统一使用已下载的压缩 Blob。背景不再在剧情途中临时联网。只逐个验证图像，不常驻整章解码后的位图或 PCM 音频。
- Cache Storage 用内容哈希区分版本；失效/损坏的条目重新取得，缓存不可用仍可用本次内存资源。最多 4 个下载；30 秒没有新数据才超时，最多重试 2 次。部分失败保留成功部分；100% 只在完整校验后出现。
- 加载屏有真实体积进度、进入章节、重试和返回大厅；游戏脚本尚未取得时，HTML 先显示“正在准备游戏”。没有新增对话按钮或提示音。

不增加存档字段，不清理玩家 localStorage。素材缓存不是存档。正常音频自动播放限制沿用原重试机制，不作为下载失败，也不等待声音播放结束才推进。

极端内存压力下浏览器仍可能回收整个标签页；本轮保证完整下载后本页内的素材读取不再依赖网络，不承诺网页关闭后在完全离线时能打开 HTML/JS（未新增 Service Worker）。

沿用本地单存档模型；未新增跨标签页存档锁。不要在两个标签页同时推进同一存档，尤其不要在一页等待加载时用另一页推进；多标签并行写入的冲突不在本轮修复范围内。
