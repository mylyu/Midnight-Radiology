# 《深夜影像科》游戏设计文档（GDD）

> 版本：v1.0 ｜ 2026-08
> 定位：医学成像原理课程的剧情向教学游戏——好玩为主，知识自然融入
> 平台：Web（React 网页版，扫码即玩，手机/电脑均可）

---

## 一、游戏概述

### 一句话设定
你是一家医院影像科新来的夜班技师。每个深夜，急诊的病人带着各自的秘密到来，而你是唯一能"看穿"他们的人。五年夜班，科室从一台老掉牙的X光机起步，一步步添置CT、超声、MRI，直到那个"查不出来"的神秘病人的答案浮出水面。

### 核心体验
- **单元剧**：每夜一个病人小故事（悬疑/温情/轻喜剧）
- **核心爽点**："开灯时刻"——选定设备，屏幕显形，亲眼看到身体内部
- **养成线**：赚钱 → 买设备 → 修设备 → 科室成长
- **收集线**：打卡日志、勋章墙、隐藏夜话

### 教学知识分层融入原则

| 知识优先级 | 玩法层 | 融入方式 |
|---|---|---|
| ① 各模态优缺点、适应症与禁忌（必会） | 每夜核心决策 | 选设备的推理决策；选错有剧情后果，选对病人得救 |
| ② 物理原理与设备构造（应会） | 经营事件 | 买/修/故障事件：坏什么学什么，在情绪峰值（心疼钱）时教学 |
| ③ 重建算法与数学（拓展，CT/MRI） | 可选彩蛋 | "技术档案"收集品 + 反投影拼图、k空间涂鸦小游戏，自愿解锁，配勋章 |

铁律：剧情里绝不说教，知识全部长在"决策、事故、账单"上。

## 二、章节结构（5章 × 每章3夜 + 1个章末大夜班）

### 第一章 X光 ——「老伙计」（第1~3夜）
- **设备**：老旧X光机（开局自带，会出故障）
- **知识①**：X光看骨骼/异物最拿手；有电离辐射，孕妇儿童慎用
- **知识②**：球管、高压发生器（借故障事件教学）
- **招牌病例**：吞纽扣电池的小孩（双环征鉴别硬币）、工地摔伤骨折大叔、瘦高个自发性气胸
- **经营事件**：老机器半夜故障——自己修还是叫师傅（第一次修理抉择）
- **伏笔**：①观察窗后的CT机房一直黑着，"那屋空了两年了"；②神秘病人首诊，X光正常，"可我真的不舒服"；③护士提到"楼下超声科"
- **章节勋章**：「老伙计的荣耀」

### 第二章 CT ——「快与狠」（第4~6夜）
- **设备**：二手CT（章初买设备大戏：贩子吹牛/验机/砍价）
- **知识①**：CT快、急诊之王；断层图像解决X光重叠问题；剂量远大于X光
- **知识②**：球管热容量（过热事件）、探测器排数（贩子吹牛素材）
- **知识③（彩蛋）**：反投影拼图小游戏解锁
- **招牌病例**：半夜脑出血vs脑梗鉴别反转、胸痛老太太不是心梗是主动脉夹层
- **经营事件**：球管过热罢工——连续扫描的节奏管理
- **伏笔**：①神秘病人CT"正常"，毒舌医生皱眉："软组织……差点意思"；②便携超声的八卦；③病历堆里一张"核医学科会诊单"一闪而过
- **章节勋章**：「黄金四分钟」

### 第三章 超声 ——「温柔的耳朵」（第7~9夜）
- **设备**：便携超声（可推到床旁，剧情场景扩展）
- **知识①**：无辐射、实时、看软组织与血流好手；怕气体、依赖操作者
- **知识②**：压电晶体探头（摔探头维修大事件，贵得肉疼）
- **招牌病例**：孕妇急诊（呼应第一章辐射知识："这次不用纠结了"）、宵夜大叔胆结石、小儿肠套叠
- **经营事件**：探头坠落事故——修还是换
- **伏笔**：①神秘病人超声下"有个影子，说不准"；②全院传闻：医院招标3.0T MRI，"那东西会把轮椅吸进去"
- **章节勋章**：「温柔的手」

### 第四章 磁共振 ——「温柔又暴躁的巨兽」（第10~12夜）
- **设备**：MRI到院，全游戏最隆重的开箱
- **知识①**：软组织分辨率天花板；慢、怕运动、禁忌多（金属植入物、幽闭恐惧）
- **知识②**：超导磁体永远有磁性（铁物吸舱拦截事件）、液氦与失超（全游戏最大场面）
- **知识③（彩蛋）**：k空间涂鸦板小游戏
- **招牌病例**：幽闭恐惧大叔（安抚玩法）、带起搏器的老人被家属推来（惊险拦截）、运动员韧带损伤
- **经营事件**：失超——液氦喷发、紧急疏散、天价重启账单
- **主线推进**：MRI看清神秘病人病灶！但"它是死是活，MRI说了不算。想知道它'活不活'，得去核医学科。"——玩家第一次听到PET
- **章节勋章**：「驯兽师」

### 第五章 PET ——「看见生命的火」（第13~15夜·结局章）
- **设备**：不购买（符合现实）——被借调核医学科，全新场景换皮
- **知识①**：PET看代谢不看形态；需与CT融合定位（PET/CT）
- **知识②**：示踪剂（氟代脱氧葡萄糖）——"给身体里的火点一盏灯"
- **主线揭晓**：神秘病人的PET/CT，五年答案揭晓（结局基调待最终确认：温情乌龙 or 早诊治愈）
- **结局**：三结局分支（见下节），尾声蒙太奇，隐藏勋章「五年的答案」
- **章节勋章**：「看见火的人」

## 三、三结局系统（一条主线 + 隐藏计分）

### 计分机制
剧情主线唯一（所有玩家玩到全部病例），关键选择累积三个隐藏数值：

| 数值 | 加减来源（示例） |
|---|---|
| **医术** | 选对设备+；识破伪影+；误诊/给禁忌人群开错检查− |
| **家业** | 修理成功+；合理采购+；失超处理不当−；乱花钱− |
| **人心** | 安抚病人+；NPC剧情选择+；敷衍病人− |

白天经营界面显示三个仪表（只显状态不显数值，🌕🌕🌕🌗🌑式）。

### 结局判定与内容
第15夜主线揭晓后，按总账进入尾声分支：

- **好结局「灯火」**：病人最佳处置 + 科室兴旺。尾声：五年后你成为顶梁柱，把打卡印章传给新夜班技师（传承）。勋章「灯火」
- **中性结局「平常夜」**：病人查清，科室起起落落。尾声：还是那间夜班室，日志盖满章——普通但认真的五年。勋章「平常夜」
- **坏结局「熄灯」**：非惩罚式——科室被合并，离别前夜神秘病人一句话点醒你，留二周目钩子。勋章「熄灯」，通关后解锁"时光机"（可跳回任意一夜重打）

### 工作量控制
结局差异内容 = 各约半夜剧情（结局夜后半段对话 + 尾声蒙太奇 + 结局勋章），无剧情树分叉。

## 四、贯穿系统

### 打卡
- **每日打卡**：现实连续登录奖励（金币、限定装饰）
- **剧情打卡**：夜班日志，每夜通关盖章+主角一句话批注；每章日志封面不同
- **连续打卡彩蛋**：连打3天解锁隐藏夜话（NPC背景故事碎片，拼出暗线）

### 勋章（软木板勋章墙）
- **剧情勋章**：火眼金睛（一夜零误诊）、电池猎手、幽闭克星……
- **经营勋章**：精打细算、设备全图鉴、修理工的荣耀（亲手修好3次）
- **章节勋章**：5枚（见各章）
- **结局勋章**：3枚 + 隐藏「五年的答案」
- **隐藏勋章**：深夜哲学家（看完所有夜话）、穷鬼的传奇（全程不买新设备）、bug猎人（试玩期反馈bug）——社交传播弹药

### 经济
- 每夜接诊赚金币 + 夜班保底收入（防卡死铁律：钱永远推得动剧情）
- 跨章继承；前章存款影响MRI采购分支（全款/贷款/二手）
- 经营失败只影响数值与勋章，永不卡关

### 设备耐久与维修
- 每台设备有耐久度，随机故障事件（每章至少1个大事件）
- 维修抉择：叫工程师（贵、慢、稳）vs 自己动手（赌）——失败有剧情兜底，不惩罚进度

### 存档
- 随时自动存档，崩了重进不丢进度
- 每夜剧情独立，可跳过单夜（防单点bug阻断）

## 七、技术与测试

### 技术栈
- React 网页版；剧本JSON驱动（每夜一个剧本文件，改剧情不碰代码）

### 防bug三层兜底
1. **开发方全通关测试**：所有对话分支、买/修设备、打卡勋章触发、乱序操作（连点/中途退出/没钱硬买）

3. **结构防死档**：保底收入、跳过单夜、自动存档、修理失败有兜底

### 试玩反馈
试玩版挂「bug猎人」勋章激励学生反馈，上线第一周集中修一轮。

## 十、作业防作弊：通关凭证（v1.0已实装）

- **实名凭证卡**：章末输入姓名+学号 → 生成盖章凭证卡（含战绩与通关码），借别人的截图名字对不上
- **校验码防伪**：通关码 = `YSK-{随机种子}-{哈希}`，哈希由 姓名+学号+金币+勋章数+夜班数+种子+盐 生成；标题界面「教师验证入口」可校验，P图改任何一项都会校验失败

## 十一、第一章扩展版（v0.2 已实装，2026-08）

试玩反馈"内容太少（3~4分钟）"后的大扩写，目标单次游戏时长 **20~30 分钟**，面向工科学生，知识点全部取自课件《第2章 X射线物理》《第3章 X射线摄影》。

### 1. 结构变化：3夜 → 5夜，每夜 = 自由行动段 + 病例工作段 + 结算

每晚开诊前获得 **行动力 ⚡×3**，可在楼内自由走动（参考《动物迷城》的时间块设计）：
- 🛒 小卖部（不耗行动力）：商店系统
- 🚶 走廊 / 🛋️ 值班室 / 🔧 设备科 / 💻 信息科 / 🏃 急诊科 / 🗄️ 旧片库：每晚随机应变的内容点，小任务换金币、闲聊攒人心、调查推悬疑
- 每个地点每晚只能去一次（旗标消耗），行动力耗尽就只能开工——**取舍即玩法**

### 3. 悬疑主线「旧片库」

旧楼传说（N1）→ 神秘男子打听老片子（N2）→ 片库夜探发现1998年无登记胶片（N3）→ CR成像板"残影"事件 + 凌晨三点的登录记录指向老周（N4）→ 真相：老周深夜为无医保的流浪老人免费拍片；神秘男子寻父二十年，与无名胶片时代吻合；片库深处封条柜留作第二章钩子（N5）。

**知识点全部借剧情自然带出**：屏片系统与潜影、CR的PSL与残影成因（老范台词+亲眼所见）、PACS日志——没有一处硬性讲解。

### 4. 知识点 → 玩法映射表

| 课件知识点 | 游戏化位置 |
|---|---|
| kV管穿透力、mAs管光子数、剂量正当化 | N1/N5 曝光参数三选一（选错重拍=双倍剂量） |
| 铅玻璃+距离防护、散射线 | N1 曝光站位选择；剂量计道具彩蛋 |
| 光电效应 vs 康普顿散射（灰雾） | N3 床旁片发灰事件 → 缩小照射野 |
| 99%热1%X光、阳极热容量 | N2 修理事件；N5 热容量报警抉择 |
| 灯丝→管电流、靶材（钨/钼/铑） | N2 修理；N4 钼靶病例 |
| 钼靶低kV特征谱、致密型乳腺选超声 | N4 体检科阿姨病例（直接拍=差评） |
| 屏片/增感屏荧光作用 | N3 片库小铁柜彩蛋（需黄铜钥匙） |
| CR潜影/PSL/擦除流程 | N2 老范台词 + N4 残影事件 |
| 非晶硅(间接) vs 非晶硒(直接) FPD | N4 雯雯推销，认真听讲有奖励 |
| 固有滤过/铝当量、铅当量 | N4 老范质控、N3 后勤对讲机 |

### 补记：v1.3.1 连点跳过扫描动画的漏洞修复（2026-08-24）

v1.3 的延迟启动开了一个窗口期：文本播完到动画启动之间有 0.8 秒，此时步骤尚未被遮罩锁定，玩家习惯性连点会把整个读取步骤直接跳过——手机上几乎必现（教师实测反馈"出图时没有动画了"）。

## 二十五、v0.4 更新：移动端适配（手机竖屏/横屏/微信浏览器）

### 问题
1. **100vh 陷阱**：根容器 h-screen 按"地址栏隐藏后"的最大高度渲染，手机浏览器地址栏可见时底部内容被切（打卡按钮消失）。
2. **竖屏裁切**：1536×1024 横版背景 object-cover 铺满，竖屏手机左右被裁约 70%。
3. 微信浏览器/iOS Safari 不支持 Fullscreen API，无法强制全屏或锁横屏。

### 方案（四层，全部兼容微信）
1. **高度根治**：JS 实测 window.innerHeight 写入 CSS 变量 --apph（监听 resize/orientationchange/visualViewport），html/body/#root 高度统一用 var(--apph)；同时保留 100dvh 作为现代浏览器原生通道，双保险。
2. **内容防切**：打卡卡片等弹层加 max-h-full + overflow-y-auto；新增 ≤480px 矮视口紧凑模式（compact-card：小内边距/小印章/小标题）。
3. **竖屏完整舞台**：BgImg 组件——横屏 object-cover 铺满；竖屏 object-contain 完整显示，空白处同图模糊放大垫底（blur-2xl scale-125 opacity-60）；立绘竖屏缩小（portrait:h-44/40）、中央大图限高 38%。全部页面共用 BgImg。
4. **细节**：viewport-fit=cover + 禁双击缩放；FullscreenBtn 仅在 document.fullscreenEnabled 时渲染（安卓 Chrome 可用，微信/iOS 自动隐藏），标题页与夜班顶栏各一枚。

## 二十六、v0.4.1 补丁:横屏立绘只显示下半身(2026-08)

- **症状**:手机横屏时立绘整体过高、头部超出屏幕,只剩下半身(用户截图反馈)。

- **教训**:移动端横屏适配要用高度断点,不能用宽度断点。

## 三十三、v0.4.8：防连点误选

### 问题
不耐烦的玩家会连续快速点击快进对话。若选项恰在连点中浮现，下一次点击就落在某个选项按钮上——玩家在没看清选项的情况下被误带进某条分支，且选项消耗行动力，误选代价不小。

### 方案：双时间戳防连点
- NightScreen 根节点用**捕获阶段** onClickCapture 维护两个 ref：每次点击把上一个 lastTapAt 存入 prevTapAt，再更新 lastTapAt（捕获阶段不受子元素 stopPropagation 影响，点选项按钮也会被记录）。
- pick() 入口判断：`Date.now() - prevTapAt.current < 700` 则忽略——即**当前这次点击距「上一次」点击不足 700ms，说明玩家处于连点快进状态，这次点到选项属于误触**。持续连点时 prevTapAt 永远刷新，永远选不中；玩家停下来超过 0.7 秒后再点，才视为有意选择。
- 配合原有的 choicesLocked（文本播完后 900ms 才显示选项，由 1200ms 下调），构成双重保险：连点玩家既看不到也点不中选项。

### 测试
- taptest.py：选项出现后在其区域以 200ms 间隔狂点 5 秒——仍停留在选项界面、未误选；停顿 1.1 秒后正常点击——选择生效。
- 全剧情自动回归（autoplay 选项点击前等待 900ms 适配锁窗）：701 步走完五夜，0 错误、0 404。

## 三十四、v0.4.9：防连点窗口放宽至 0.3 秒

### 调整
- 教师反馈 0.7 秒判定偏严：性子急但并非狂点的玩家，快速点选时会被误拦。
- pick() 的连点判定窗口由 700ms 下调为 **300ms**：只有 0.3 秒以内的贴脸连点（真正意义的"狂点"）才被拦截，0.3 秒以上的快速点选正常生效。
- choicesLocked 的 900ms 延迟浮现保持不变，作为第一道保险。

### 测试
- 150ms 间隔狂点 5 秒——零误选；停顿 350ms / 400ms 后点选均正常生效。
