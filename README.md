# 深夜影像科 / Midnight Radiology

《深夜影像科》是一款以医学影像科夜班为背景的互动叙事教学游戏。玩家通过病例处置、设备维护、知识测验与剧情选择，学习医学影像的基础知识与职业规范。

## 项目结构

- `app/`：可构建、可运行的 React + TypeScript + Vite 游戏项目。
- `深夜影像科/`：游戏设计文档和原始素材。
- `语音样张/`：语音与音效样张。
- 根目录其他素材和测试文件：保留自原始开发包，供研究、参考与再创作使用。

## 本地运行

需要 Node.js 20 或更高版本。在 `app/` 目录中执行：

```bash
npm ci
npm run dev
```

构建生产版本：

```bash
npm run build
```
